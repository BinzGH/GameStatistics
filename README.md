# BiNZ Sports Analytics — Fresh Build

## Publish on GitHub Pages
1. Upload the **contents** of this folder to the root of your GitHub repository (not the ZIP file and not the containing folder).
2. Confirm `index.html` is visible at the repository root beside `manifest.webmanifest` and `sw.js`.
3. In Settings → Pages, select Deploy from a branch, branch `main`, folder `/ (root)`, then Save.
4. Wait for GitHub Pages to finish deploying.

## Install on iPhone
Open the published HTTPS site in Safari → Share → Add to Home Screen.

## Included tools
- Value Finder: American odds, implied probability, edge, expected value.
- Player Props: normal approximation from user-provided mean, standard deviation, line, side, and odds.
- Injury Impact: hypothetical team points and win-probability adjustment.
- Pick Tracker: device-local storage, result status, and CSV export.

## Important
This app does not include live sportsbook odds, official injury feeds, or guaranteed predictions. Inputs are user-provided. Pick records stay in the current browser/device unless exported. This is an analytical and record-keeping tool, not betting advice.
